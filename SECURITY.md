# Security Policy / 보안 정책

## Supported Versions / 지원 대상 브랜치

| Branch / 브랜치 | Supported / 지원 여부 |
| --- | --- |
| `main` | Yes / 지원 |

Only the latest state of the `main` branch in `AquilaXk/easysubway-platform` receives security updates.

`AquilaXk/easysubway-platform` 저장소는 `main` 브랜치의 최신 상태에 대해서만 보안 업데이트를 제공합니다.

## Reporting a Vulnerability / 보안 취약점 제보

Report security vulnerabilities privately through [GitHub Security Advisories](https://github.com/AquilaXk/easysubway-platform/security/advisories/new) on `AquilaXk/easysubway-platform`.

보안 취약점은 공개 이슈나 Pull Request로 등록하지 말고 `AquilaXk/easysubway-platform` 저장소의 [GitHub Security Advisories](https://github.com/AquilaXk/easysubway-platform/security/advisories/new) 비공개 제보 기능으로 접수해 주시기 바랍니다.

## Disclosure Rules / 제보 시 유의사항

- Do not open public GitHub issues, discussions, or pull requests for suspected vulnerabilities.
- Never post live secrets, tokens, credentials, private keys, or destructive exploit payloads in any public issue, pull request, or comment.
- Include the affected file or workflow path, reproduction steps, and impact assessment in your private report so the maintainers can verify and remediate the issue promptly.

- 취약점 의심 사항은 공개 GitHub Issue, Discussion, Pull Request에 게시하지 마십시오.
- 실제 시크릿, 토큰, 자격 증명, 개인키, 공격 페이로드를 공개 이슈, Pull Request, 코멘트에 절대 올리지 마십시오.
- 영향받는 파일이나 워크플로 경로, 재현 절차, 영향 범위를 비공개 제보에 포함해 주시면 신속하게 확인하고 조치하겠습니다.
