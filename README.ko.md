# 쉬운 지하철 플랫폼

### 쉬운 지하철이 예측 가능하게 배포되고, 상태를 확인하며, 안전하게 동작하도록.

EasySubway가 예측 가능하게 배포되고, 상태를 확인하며, 필요한 데이터를 복구할 수 있도록 운영 기반을 만듭니다.

## Platform이 책임지는 일
- **K3s 배포 파이프라인**: 고정 다이제스트(immutable digest) 기반 backend 이미지를 ARM64 서버에 배포합니다.
- **연결 상태 확인**: 트래픽을 연결하기 전 데이터베이스 접속, 시크릿 설정, 서비스 응답 상태를 확인합니다.
- **트래픽 전환**: 새 파드가 준비되면 호스트 Nginx 프록시를 대상 NodePort로 전환하고 이전 워크로드를 정리합니다.
- **안전 중단**: 필수 설정이나 실행 조건이 어긋나면 배포를 즉시 멈춰 잘못된 상태로 트래픽이 열리지 않게 합니다.
- **관측과 백업**: Prometheus 메트릭, Alertmanager 알림, PostgreSQL 및 파일 스토리지 백업과 복구 리허설을 운영합니다.

## 현재 범위
현재 Platform은 K3s 기반 Journey V3 운영 환경과 배포 인프라를 담당하며, 고정 백엔드 이미지와 데이터팩 번들, 호스트 라우팅 구성을 안정적으로 연결합니다.
